• Guests can only add up to images per dataset. If you want to try the software on other data, please delete entries or create a new dataset.
  • We recommend to name your files according one of the following patterns: [type]_[experiment]_[sample]_[time point]_[disk diameter].png, [experiment]_[sample]_[time point]_[disk diameter].png, or [sample]_[time point]_[disk diameter].png.
    If the type starts with a d, it will be interpreted as DDA. The disk diameter is provided in mm.
  • Please note that the images are organized by experiment, sample, and time point.
  • Each (experiment, sample) combination must have exactly two time points.
